📋 JSON 포맷터 & 검증기

복잡한 JSON 코드를 보기 좋게 정렬하거나 압축하세요.

JSON 포맷터란?

JSON(JavaScript Object Notation)은 서버와 클라이언트가 데이터를 주고받을 때 가장 많이 쓰이는 텍스트 형식입니다. 하지만 서버 로그, API 응답값, DB에 저장된 설정값 등은 보통 용량을 줄이기 위해 공백 없이 한 줄로 뭉쳐져 있어(Minified) 사람이 눈으로 구조를 파악하기 어렵습니다. 이 도구는 그런 JSON을 들여쓰기가 적용된 읽기 좋은 형태(Prettify)로 바꾸거나, 반대로 불필요한 공백을 제거해 압축(Minify)하고, 문법에 문제가 있는 경우 어느 부분이 어떻게 잘못됐는지 즉시 알려주는 검증(Validation) 기능을 제공합니다.

사용 방법

  • 정렬 (Beautify): 왼쪽 입력창에 JSON을 붙여넣고 버튼을 누르면 2칸 들여쓰기가 적용된 구조로 변환됩니다.
  • 압축 (Minify): 개행과 공백을 모두 제거해 네트워크 전송량이나 파일 용량을 줄입니다.
  • 검증: 버튼을 누르는 즉시 JSON.parse 결과를 확인해 콤마 누락, 따옴표 누락, 후행 콤마(trailing comma) 같은 흔한 오류의 위치를 안내합니다.

실제로 언제 쓰이나요?

  • API 응답 디버깅: 개발자 도구 네트워크 탭에서 복사한 압축된 응답값을 붙여넣어 구조를 빠르게 파악할 때.
  • 설정 파일 정리: package.json, tsconfig.json 등 설정 파일을 손으로 편집하기 전 형식을 검증할 때.
  • 로그 분석: 서버 로그에 한 줄로 남은 JSON 이벤트를 사람이 읽을 수 있는 형태로 바꿔 원인을 추적할 때.
  • API 문서/이슈 공유: 팀원에게 응답 예시를 공유하기 전 보기 좋게 정렬해서 붙여넣을 때.

자주 묻는 질문

Q. "Unexpected token" 오류가 나요. 무슨 뜻인가요?
JSON 문법에 맞지 않는 부분이 있다는 뜻입니다. 흔한 원인은 문자열에 작은따옴표(')를 쓴 경우(JSON은 반드시 큰따옴표만 허용), 마지막 항목 뒤에 콤마가 남아있는 경우(trailing comma), 키를 따옴표 없이 쓴 경우입니다.

Q. 입력한 데이터가 서버로 전송되나요?
아니요. 이 페이지의 정렬/압축/검증은 브라우저 안의 자바스크립트(JSON.parse, JSON.stringify)만으로 처리되며, 입력값은 어디로도 전송되거나 저장되지 않습니다. 민감한 API 응답값을 붙여넣어도 안전합니다.

Q. 들여쓰기 간격을 바꿀 수 있나요?
현재는 2칸 들여쓰기로 고정되어 있습니다. 4칸 들여쓰기 등 커스텀 옵션이 필요하면 문의 페이지로 요청해 주세요.
